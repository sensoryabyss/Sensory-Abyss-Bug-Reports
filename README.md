# Sensory-Abyss-Bug-Reports
This is the official Sensory Abyss bug report catalog. You don't need a GitHub account to send a report.

## How to report a bug

**From the web:** https://bugs.sensoryabyss.workers.dev

**From the game (starting with the next update):** open the journal, go to **Credits → Report a Bug**, and click **Report a bug**, or type `/sabugreport` in chat. Your mod version and game log are filled in for you.

## Before you report

Search the open issues here first. If your bug is already listed, you can add to it with a comment (that needs a GitHub account), or just send the form anyway and I'll merge them.

I read every report. When a fix ships, I close the issue.
